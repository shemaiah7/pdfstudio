# PDF Studio

Browser-based PDF editor with AI assist. Files never leave the browser except page images you explicitly send with Deep OCR; AI features send extracted text through a Cloudflare Worker to Claude.

- `npm run dev` – app on http://localhost:5173 (copy `.env.example` to `.env`)
- `npm run worker:dev` – AI proxy on http://localhost:8787 (see `worker/README.md`)
- `npm test`, `npm run worker:test`, `npm run e2e`

**Markup and forms.** Tools: highlight, note, draw, rectangle, arrow, text box and sign. Existing form fields can be filled in, with a Clear form button to reset them. Signatures can be drawn, typed or uploaded; "Remember" stores the signature only in this browser's localStorage and it is never sent anywhere. Downloads keep annotations editable in Acrobat and Preview, while signatures are flattened into the page.

**Search.** Enable search once to download about 200 MB of embedding model (EmbeddingGemma 2, Apache 2.0) into the browser. Opened documents are chunked and indexed on this device only, kept in a local library so they stay searchable on later visits, and Ask can answer from the most relevant passages instead of the whole file. Nothing about your documents is sent anywhere; the model files come from Hugging Face's CDN, and the ONNX runtime (WebAssembly or WebGPU backend) is fetched from a CDN on first use and contains no document data. Search needs WebGPU (Chrome, Edge, Safari 26+, Firefox 141+); browsers without it can opt into a CPU mode that downloads about 1 GB per visit. `npm run search:smoke` checks the model locally; `E2E_SEARCH=1 npm run e2e` runs the browser test that downloads it.

**OCR.** Scanned pages are recognized automatically in the browser with Tesseract.js (English; language data is downloaded from jsDelivr and cached). The text powers selection, AI features, search, and is written into downloaded PDFs as an invisible layer. "Deep OCR" sends page images to the AI worker for Claude to transcribe handwriting, tables, and photos; it is opt-in per use and costs one AI request per page. Turn automatic recognition off under the AI panel's "Recognize text automatically".

**Scanned image formats.** JBIG2 and JPEG 2000 page images are decoded with pdf.js WebAssembly modules that the build copies from `pdfjs-dist` into `/pdfjs-wasm/<version>/` (served with the app, no CDN). `npm run fixtures:jbig2` regenerates the JBIG2 test fixture (needs Python 3 with Pillow built against libtiff, and PyMuPDF).

**Edit text.** Choose *Edit text* (or press `e`), In the Edit tool, drag a box over the text you want to change (or click a single line). Each line in the box becomes its own field, pre-styled with its original bold, regular, and italic runs and sizes; type inside a run and the new text keeps that run's style. Press Enter or Done and only the lines you changed are replaced, drawn in matching standard faces over a cover in the page's own colour; everything else on the page is untouched. Emptying a field whites the line out. The original is covered in the page's own background colour and the new text is drawn in the closest of the twelve standard PDF faces (Helvetica, Times, Courier and their bold/italic variants), matched from the original font's name and flags. Edits reflow inside the block, can be reopened, moved, resized, re-fonted or deleted, and are included in Summarize, Ask, Search, and the downloaded PDF. On scanned pages the recognized text is updated too. When you download, edited typed pages are flattened to an image with an invisible text layer so the covered original text cannot be copied or searched; scanned pages keep their recognized text. Pages must be shown unrotated to edit.

**Voice.** The Voice tab starts a spoken conversation about the open document with an ElevenLabs agent whose language model is Claude Sonnet 5.5. The agent cannot see the document; it calls a `search_document` tool that runs in your browser (the same on-device retrieval as Ask, with keyword matching when the search model is not loaded) and answers only from the passages returned, citing pages. Microphone audio goes to ElevenLabs; returned passages go to ElevenLabs and Anthropic. The agent is configured not to record audio and to delete transcripts; nothing is kept by PDF Studio. Sessions last up to 10 minutes and end after 2 minutes of silence; the shared allowance is 30 minutes per visitor per day. Operators provision the agent with `npx tsx worker/scripts/provision-agent.ts` (reads `worker/.dev.vars`) and set `ELEVENLABS_AGENT_ID` in `worker/wrangler.jsonc`. The operator also sets `ELEVENLABS_API_KEY` with `cd worker && npx wrangler secret put ELEVENLABS_API_KEY`, puts `ELEVENLABS_AGENT_ID` in `worker/.dev.vars` for the smoke script, and runs `E2E_LIVE=1 npx tsx worker/scripts/live-smoke.ts` to verify. The agent runs in ElevenLabs zero-retention mode.
