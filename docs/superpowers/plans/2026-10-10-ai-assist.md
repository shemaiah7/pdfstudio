# AI Assist Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an AI panel to PDF Studio (summarize, ask, rewrite with insert-into-PDF, extract) backed by a Cloudflare Worker proxy to Claude with per-visitor daily limits and a Turnstile bot check.

**Architecture:** A separate npm package in `worker/` (Cloudflare Worker, TypeScript) exposes `POST /session` and `POST /ai`; it owns the prompts, validates bodies with zod, tracks quota in KV, calls Claude Sonnet 5.5 through the official SDK with streaming, and re-emits a simple SSE protocol. The React app extracts page text with pdf.js, adds a selectable text layer, streams results into a Zustand AI store, and stores overlay edits in the document store so pdf-lib can draw them on export.

**Tech Stack:** `@anthropic-ai/sdk`, zod, Cloudflare Workers + KV + Wrangler, `@cloudflare/vitest-plugin`, pdfjs-dist `TextLayer`, pdf-lib, React 19, Zustand, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-10-ai-assist-design.md`

## Global Constraints

- Model is exactly `claude-sonnet-5-5`; `max_tokens: 8000`; no explicit `thinking` param; `output_config.effort` is `low` for summarize/ask/rewrite and `medium` for extract.
- Fallbacks: `betas: ["server-side-fallback-2026-07-01"]` and `fallbacks: "default"` on `client.beta.messages.stream`.
- Daily limit per visitor: 20 requests and 200,000 tokens per UTC day; burst limit 5 requests per 60 seconds.
- Body limits: document ≤ 600,000 chars total; selection ≤ 20,000 chars; question ≤ 2,000 chars; history ≤ 10 turns.
- PDF bytes never leave the browser; only extracted text is sent.
- The Worker never logs document text, selections, or questions.
- Anthropic error bodies are never forwarded to the browser.
- CORS allows only `ALLOWED_ORIGIN`.
- Design rulings made in this plan: (1) burst limiting uses KV, not the rate-limit binding, so one quota module covers both limits and is testable locally; (2) "Insert into PDF" is enabled only when the page's effective rotation is 0 (source `/Rotate` plus user rotation), so overlay and export share coordinates.
- Do not add Turnstile site keys or Worker URLs to source; they come from `VITE_*` env vars and `.dev.vars`.

## Review Focus

1. A page with text in two columns: extracted lines must not interleave the columns into gibberish; grouping by y with an x-order tiebreak keeps each line's words in reading order within the line. (Test in Task 6.)
2. The SSE stream arrives with one event split across two network chunks, or two events in one chunk: the parser must emit each event exactly once. (Test in Task 7.)
3. A visitor's 20th request starts at 23:59:50 UTC and finishes after midnight: usage must be charged to the day the request started, and the 21st request after midnight must be allowed. (Test in Task 3.)
4. A selection that spans two lines where the second line is shorter: the edit's white boxes must cover only the selected glyphs' rectangles, not the full width of both lines. (Test in Task 9.)
5. The replacement text is far longer than the original: Insert must be disabled with an overflow message rather than drawing text over the rest of the page. (Test in Task 9.)

```ts
import type { Env } from "./env";

export function corsHeaders(env: Env): Record<string, string> {
  return {
    "access-control-allow-origin": env.ALLOWED_ORIGIN,
    "access-control-allow-methods": "POST, OPTIONS",
    "access-control-allow-headers": "authorization, content-type",
    "access-control-max-age": "86400",
    vary: "origin",
  };
}

export function json(body: unknown, status: number, env: Env, extra: Record<string, string> = {}): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { "content-type": "application/json", ...corsHeaders(env), ...extra },
  });
}
```

`worker/src/index.ts`:

```ts
import type { Env } from "./env";
import { corsHeaders, json } from "./cors";

export type Handler = (request: Request, env: Env, ctx: ExecutionContext) => Promise<Response>;

const routes: Record<string, Handler> = {
  "/session": async (_r, env) => json({ error: "not_implemented" }, 501, env),
  "/ai": async (_r, env) => json({ error: "not_implemented" }, 501, env),
};

export default {
  async fetch(request: Request, env: Env, ctx: ExecutionContext): Promise<Response> {
    if (request.method === "OPTIONS") {
      return new Response(null, { status: 204, headers: corsHeaders(env) });
    }
    const { pathname } = new URL(request.url);
    const handler = routes[pathname];
    if (!handler) return json({ error: "not_found" }, 404, env);
    if (request.method !== "POST") return json({ error: "method_not_allowed" }, 405, env);
    return handler(request, env, ctx);
  },
};

export function registerRoute(path: string, handler: Handler): void {
  routes[path] = handler;
}
```

Note: later tasks replace the two stub entries directly in `routes` with imports; `registerRoute` exists only so tests can swap handlers if needed.

`worker/src/session.ts`:

```ts
export interface SessionPayload { vid: string; exp: number }

const enc = new TextEncoder();

function b64url(bytes: ArrayBuffer | Uint8Array | string): string {
  const bin = typeof bytes === "string" ? bytes : String.fromCharCode(...new Uint8Array(bytes));
  return btoa(bin).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

function fromB64url(s: string): string {
  const pad = s.length % 4 === 0 ? "" : "=".repeat(4 - (s.length % 4));
  return atob(s.replace(/-/g, "+").replace(/_/g, "/") + pad);
}

async function hmac(data: string, secret: string): Promise<string> {
  const key = await crypto.subtle.importKey("raw", enc.encode(secret), { name: "HMAC", hash: "SHA-256" }, false, ["sign"]);
  return b64url(await crypto.subtle.sign("HMAC", key, enc.encode(data)));
}

export function utcDay(now: number = Date.now() / 1000): string {
  return new Date(now * 1000).toISOString().slice(0, 10);
}

export async function visitorId(ip: string, secret: string, day: string): Promise<string> {
  const digest = await crypto.subtle.digest("SHA-256", enc.encode(`${secret}|${day}|${ip}`));
  return [...new Uint8Array(digest).slice(0, 8)].map((b) => b.toString(16).padStart(2, "0")).join("");
}

export async function signSession(payload: SessionPayload, secret: string): Promise<string> {
  const p = b64url(JSON.stringify(payload));
  return `${p}.${await hmac(p, secret)}`;
}

export async function verifySession(token: string, secret: string, now: number = Date.now() / 1000): Promise<SessionPayload | null> {
  const parts = token.split(".");
  if (parts.length !== 2) return null;
  const [p, sig] = parts;
  if ((await hmac(p, secret)) !== sig) return null;
  try {
    const payload = JSON.parse(fromB64url(p)) as SessionPayload;
    if (typeof payload.vid !== "string" || typeof payload.exp !== "number") return null;
    if (payload.exp <= now) return null;
    return payload;
  } catch {
    return null;
  }
}
```

`worker/src/turnstile.ts`:

```ts
import type { Env } from "./env";

export async function verifyTurnstile(token: string, ip: string, env: Env, fetchFn: typeof fetch = fetch): Promise<boolean> {
  if (!token || token.length > 2048) return false;
  const allowed = new Set(env.TURNSTILE_HOSTNAMES.split(",").map((h) => h.trim()).filter(Boolean));
  try {
    const r = await fetchFn("https://challenges.cloudflare.com/turnstile/v0/siteverify", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ secret: env.TURNSTILE_SECRET, response: token, remoteip: ip }),
      signal: AbortSignal.timeout(10_000),
    });
    if (!r.ok) return false;
    const result = (await r.json()) as { success?: boolean; hostname?: string };
    return result.success === true && typeof result.hostname === "string" && allowed.has(result.hostname);
  } catch {
    return false;
  }
}
```

`worker/src/handlers/session.ts`:

```ts
import type { Env } from "../env";
import { json } from "../cors";
import { verifyTurnstile } from "../turnstile";
import { signSession, utcDay, visitorId } from "../session";

export async function sessionHandler(request: Request, env: Env): Promise<Response> {
  let token = "";
  try {
    const body = (await request.json()) as { turnstileToken?: unknown };
    if (typeof body.turnstileToken === "string") token = body.turnstileToken;
  } catch { /* fall through */ }
  const ip = request.headers.get("cf-connecting-ip") ?? "0.0.0.0";
  if (!(await verifyTurnstile(token, ip, env))) return json({ error: "verification_failed" }, 403, env);
  const now = Math.floor(Date.now() / 1000);
  const exp = now + 24 * 3600;
  const vid = await visitorId(ip, env.SESSION_SECRET, utcDay(now));
  return json({ token: await signSession({ vid, exp }, env.SESSION_SECRET), expiresAt: exp }, 200, env);
}
```

### Task 3: Quota in KV (daily and burst)

**Files:**
- Create: `worker/src/quota.ts`, `worker/test/quota.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export const DAILY_REQUESTS = 20;
  export const DAILY_TOKENS = 200_000;
  export const BURST_REQUESTS = 5;
  export interface QuotaState { requests: number; tokens: number }
  export type QuotaCheck =
    | { ok: true; remaining: { requests: number; tokens: number }; resetAt: number; day: string }
    | { ok: false; reason: "daily_limit" | "too_fast"; resetAt: number };
  export async function checkQuota(kv: KVNamespace, vid: string, now?: number): Promise<QuotaCheck>
  export async function recordUsage(kv: KVNamespace, vid: string, day: string, tokens: number): Promise<QuotaState>
  export function nextUtcMidnight(now?: number): number  // unix seconds
  ```
  `checkQuota` also increments the burst counter for the current minute (key `b:<vid>:<minute>`, TTL 120 s). `recordUsage` adds one request and `tokens` to `q:<vid>:<day>` (TTL 2 days). KV writes are read-modify-write; small races are acceptable for soft limits.

```ts
import { utcDay } from "./session";

export const DAILY_REQUESTS = 20;
export const DAILY_TOKENS = 200_000;
export const BURST_REQUESTS = 5;

export interface QuotaState { requests: number; tokens: number }
export type QuotaCheck =
  | { ok: true; remaining: { requests: number; tokens: number }; resetAt: number; day: string }
  | { ok: false; reason: "daily_limit" | "too_fast"; resetAt: number };

export function nextUtcMidnight(now: number = Date.now() / 1000): number {
  const d = new Date(now * 1000);
  return Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate() + 1) / 1000;
}

async function readState(kv: KVNamespace, key: string): Promise<QuotaState> {
  return (await kv.get<QuotaState>(key, "json")) ?? { requests: 0, tokens: 0 };
}

export async function checkQuota(kv: KVNamespace, vid: string, now: number = Date.now() / 1000): Promise<QuotaCheck> {
  const day = utcDay(now);
  const resetAt = nextUtcMidnight(now);
  const minute = Math.floor(now / 60);
  const burstKey = `b:${vid}:${minute}`;
  const burst = Number((await kv.get(burstKey)) ?? "0");
  if (burst >= BURST_REQUESTS) return { ok: false, reason: "too_fast", resetAt: (minute + 1) * 60 };
  await kv.put(burstKey, String(burst + 1), { expirationTtl: 120 });

  const state = await readState(kv, `q:${vid}:${day}`);
  if (state.requests >= DAILY_REQUESTS || state.tokens >= DAILY_TOKENS) {
    return { ok: false, reason: "daily_limit", resetAt };
  }
  return {
    ok: true,
    day,
    resetAt,
    remaining: { requests: DAILY_REQUESTS - state.requests, tokens: DAILY_TOKENS - state.tokens },
  };
}

export async function recordUsage(kv: KVNamespace, vid: string, day: string, tokens: number): Promise<QuotaState> {
  const key = `q:${vid}:${day}`;
  const state = await readState(kv, key);
  const next = { requests: state.requests + 1, tokens: state.tokens + Math.max(0, tokens) };
  await kv.put(key, JSON.stringify(next), { expirationTtl: 2 * 86400 });
  return next;
}
```

```ts
import { z } from "zod";

export const MAX_DOC_CHARS = 600_000;
export const MAX_SELECTION_CHARS = 20_000;
export const MAX_QUESTION_CHARS = 2_000;

const pageSchema = z.object({ page: z.number().int().positive(), text: z.string() });
const turnSchema = z.object({ role: z.enum(["user", "assistant"]), text: z.string().max(8_000) });

const base = z.object({
  document: z.array(pageSchema).min(1).max(2_000),
});

const schema = z.discriminatedUnion("task", [
  base.extend({ task: z.literal("summarize") }),
  base.extend({
    task: z.literal("ask"),
    question: z.string().min(1).max(MAX_QUESTION_CHARS),
    history: z.array(turnSchema).max(10).optional(),
  }),
  base.extend({
    task: z.literal("rewrite"),
    selection: z.string().min(1).max(MAX_SELECTION_CHARS),
    mode: z.enum(["rewrite", "simplify", "formal", "translate", "explain"]),
    language: z.string().min(1).max(40).optional(),
  }).refine((b) => b.mode !== "translate" || !!b.language, { message: "language required for translate" }),
  base.extend({ task: z.literal("extract") }),
]);

export type AiBody = z.infer<typeof schema>;
export type Task = AiBody["task"];
export type RewriteMode = "rewrite" | "simplify" | "formal" | "translate" | "explain";
export type Validation =
  | { ok: true; body: AiBody }
  | { ok: false; status: 400 | 413; error: string; maxChars?: number };

export function validateAiBody(input: unknown): Validation {
  const parsed = schema.safeParse(input);
  if (!parsed.success) return { ok: false, status: 400, error: "invalid_body" };
  const total = parsed.data.document.reduce((n, p) => n + p.text.length, 0);
  if (total > MAX_DOC_CHARS) return { ok: false, status: 413, error: "document_too_large", maxChars: MAX_DOC_CHARS };
  return { ok: true, body: parsed.data };
}
```

```ts
import type Anthropic from "@anthropic-ai/sdk";
import { PROMPTS } from "./prompts";
import type { AiBody } from "./validate";

export const MODEL = "claude-sonnet-5-5";

export const EXTRACT_SCHEMA = {
  type: "object",
  properties: {
    facts: {
      type: "array",
      items: {
        type: "object",
        properties: {
          label: { type: "string" },
          value: { type: "string" },
          page: { type: "integer" },
        },
        required: ["label", "value", "page"],
        additionalProperties: false,
      },
    },
  },
  required: ["facts"],
  additionalProperties: false,
} as const;

function escapeText(s: string): string {
  return s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;");
}

function documentBlock(doc: AiBody["document"]): Anthropic.Beta.BetaTextBlockParam {
  const text = `<document>\n${doc.map((p) => `<page n="${p.page}">${escapeText(p.text)}</page>`).join("\n")}\n</document>`;
  return { type: "text", text, cache_control: { type: "ephemeral" } };
}

export type BuiltRequest = Anthropic.Beta.MessageStreamParams & {
  system: Anthropic.Beta.BetaTextBlockParam[];
  betas: string[];
  fallbacks: "default";
};

export function buildRequest(body: AiBody): BuiltRequest {
  const system: Anthropic.Beta.BetaTextBlockParam[] = [
    { type: "text", text: PROMPTS[body.task], cache_control: { type: "ephemeral" } },
  ];
  const doc = documentBlock(body.document);
  const messages: Anthropic.Beta.BetaMessageParam[] = [];
  let effort: "low" | "medium" = "low";
  let format: Record<string, unknown> | undefined;

  switch (body.task) {
    case "summarize":
      messages.push({ role: "user", content: [doc, { type: "text", text: "Summarize this document." }] });
      break;
    case "ask": {
      const history = body.history ?? [];
      if (history.length === 0) {
        messages.push({ role: "user", content: [doc, { type: "text", text: body.question }] });
      } else {
        messages.push({ role: "user", content: [doc, { type: "text", text: history[0].text }] });
        for (const turn of history.slice(1)) messages.push({ role: turn.role, content: [{ type: "text", text: turn.text }] });
        messages.push({ role: "user", content: [{ type: "text", text: body.question }] });
      }
      break;
    }
    case "rewrite": {
      const lines = [`Mode: ${body.mode}`];
      if (body.mode === "translate") lines.push(`Target language: ${body.language}`);
      lines.push(`<selection>${escapeText(body.selection)}</selection>`);
      messages.push({ role: "user", content: [doc, { type: "text", text: lines.join("\n") }] });
      break;
    }
    case "extract":
      effort = "medium";
      format = { type: "json_schema", schema: EXTRACT_SCHEMA };
      messages.push({ role: "user", content: [doc, { type: "text", text: "Extract the key facts." }] });
      break;
  }

  return {
    model: MODEL,
    max_tokens: 8000,
    system,
    messages,
    output_config: format ? { effort, format } : { effort },
    betas: ["server-side-fallback-2026-07-01"],
    fallbacks: "default",
  } as BuiltRequest;
}
```

Note on the `ask` history: the first history turn must be a user turn (the client guarantees it); if `history[0].role` is `assistant`, drop it before building. Add that line: `const history = (body.history ?? []).filter((t, i) => !(i === 0 && t.role === "assistant"));`. Also collapse consecutive same-role turns is unnecessary (the API merges them).

If TypeScript complains about `output_config.format` or `fallbacks` not being in the SDK's param types, keep the `as BuiltRequest` cast and widen `BuiltRequest` with `& Record<string, unknown>`; do not drop the fields.

```ts
export type Send = (event: string, data: unknown) => void;

export function sseResponse(env: Env, run: (send: Send) => Promise<void>): Response {
  const encoder = new TextEncoder();
  const stream = new ReadableStream<Uint8Array>({
    async start(controller) {
      const send: Send = (event, data) => {
        controller.enqueue(encoder.encode(`event: ${event}\ndata: ${JSON.stringify(data)}\n\n`));
      };
      try {
        await run(send);
      } catch {
        send("error", { error: "upstream" });
      } finally {
        controller.close();
      }
    },
  });
  return new Response(stream, {
    status: 200,
    headers: { "content-type": "text/event-stream", "cache-control": "no-cache", ...corsHeaders(env) },
  });
```

```ts
import Anthropic from "@anthropic-ai/sdk";
import type { Env } from "./env";
import type { BuiltRequest } from "./request";

export interface StreamResult {
  events: AsyncIterable<{ type: "text"; text: string }>;
  final(): Promise<{ inputTokens: number; outputTokens: number; stop: string }>;
}
export type StreamFn = (params: BuiltRequest, env: Env) => Promise<StreamResult>;

export const streamWithSdk: StreamFn = async (params, env) => {
  const client = new Anthropic({ apiKey: env.ANTHROPIC_API_KEY, maxRetries: 1 });
  const stream = client.beta.messages.stream(params);
  const events = (async function* () {
    for await (const event of stream) {
      if (event.type === "content_block_delta" && event.delta.type === "text_delta") {
        yield { type: "text" as const, text: event.delta.text };
      }
    }
  })();
  return {
    events,
    async final() {
      const m = await stream.finalMessage();
      const u = m.usage;
      const inputTokens = (u.input_tokens ?? 0) + (u.cache_creation_input_tokens ?? 0) + (u.cache_read_input_tokens ?? 0);
      return { inputTokens, outputTokens: u.output_tokens ?? 0, stop: m.stop_reason ?? "end_turn" };
    },
  };
};

export function mapError(err: unknown): "busy" | "upstream" {
  const status = (err as { status?: number })?.status;
  if (status === 429 || status === 529 || (status !== undefined && status >= 500)) return "busy";
  if (err instanceof Anthropic.RateLimitError || err instanceof Anthropic.InternalServerError) return "busy";
  return "upstream";
}
```

```ts
import type { Env } from "../env";
import { json } from "../cors";
import { verifySession } from "../session";
import { validateAiBody } from "../validate";
import { buildRequest } from "../request";
import { checkQuota, recordUsage, DAILY_REQUESTS, DAILY_TOKENS } from "../quota";
import { streamWithSdk, mapError, type StreamFn } from "../claude";
import { sseResponse } from "../sse";

export async function aiHandler(request: Request, env: Env, ctx: ExecutionContext, stream: StreamFn = streamWithSdk): Promise<Response> {
  const auth = request.headers.get("authorization") ?? "";
  const token = auth.startsWith("Bearer ") ? auth.slice(7) : "";
  const session = token ? await verifySession(token, env.SESSION_SECRET) : null;
  if (!session) return json({ error: "unauthorized" }, 401, env);

  let raw: unknown;
  try { raw = await request.json(); } catch { return json({ error: "invalid_body" }, 400, env); }
  const v = validateAiBody(raw);
  if (!v.ok) return json({ error: v.error, ...(v.maxChars ? { maxChars: v.maxChars } : {}) }, v.status, env);

  const quota = await checkQuota(env.QUOTA, session.vid);
  if (!quota.ok) return json({ error: quota.reason, resetAt: quota.resetAt }, 429, env);

  let result;
  try {
    result = await stream(buildRequest(v.body), env);
  } catch (err) {
    const kind = mapError(err);
    console.log(JSON.stringify({ task: v.body.task, vid: session.vid, status: "error", kind }));
    return json({ error: kind }, kind === "busy" ? 503 : 502, env);
  }

  const { day, resetAt } = quota;
  return sseResponse(env, async (send) => {
    try {
      for await (const e of result.events) send("delta", { text: e.text });
    } catch {
      send("error", { error: "upstream" });
      return;
    }
    const f = await result.final();
    const tokens = f.inputTokens + f.outputTokens;
    const state = await recordUsage(env.QUOTA, session.vid, day, tokens);
    console.log(JSON.stringify({ task: v.body.task, vid: session.vid, status: f.stop, tokens }));
    if (f.stop === "refusal") { send("error", { error: "refused" }); return; }
    send("done", {
      usage: { input: f.inputTokens, output: f.outputTokens },
      stop: f.stop,
      remaining: { requests: Math.max(0, DAILY_REQUESTS - state.requests), tokens: Math.max(0, DAILY_TOKENS - state.tokens) },
      resetAt,
    });
  });
}
```

```ts
import * as pdfjs from "pdfjs-dist";
import type { SourceFile, SourceId } from "./types";

export interface TextItemBox { str: string; x: number; y: number; width: number; height: number; fontSize: number }
export interface PageText { text: string; items: TextItemBox[] }

interface RawItem { str: string; transform: number[]; width: number; height: number; hasEOL?: boolean }

export function linesFromItems(items: RawItem[]): string {
  const placed = items
    .filter((i) => i.str.length > 0)
    .map((i) => ({ str: i.str, x: i.transform[4], y: i.transform[5], w: i.width, size: Math.hypot(i.transform[2], i.transform[3]) || 10 }));
  // Group into lines: same baseline within half the font size.
  placed.sort((a, b) => b.y - a.y || a.x - b.x);
  const lines: (typeof placed)[] = [];
  for (const p of placed) {
    const line = lines[lines.length - 1];
    if (line && Math.abs(line[0].y - p.y) <= line[0].size * 0.5) line.push(p);
    else lines.push([p]);
  }
  return lines
    .map((line) => {
      line.sort((a, b) => a.x - b.x);
      let out = "";
      let cursor = -Infinity;
      for (const p of line) {
        const gap = p.x - cursor;
        if (out && gap > p.size * 0.15 && !out.endsWith(" ") && !p.str.startsWith(" ")) out += " ";
        out += p.str;
        cursor = p.x + p.w;
      }
      return out.replace(/\s+/g, " ").trim();
    })
    .filter((l) => l.length > 0)
    .join("\n");
}

export function hasAnyText(pages: { text: string }[]): boolean {
  return pages.some((p) => p.text.trim().length > 0);
}

const cache = new Map<string, Promise<PageText>>();
const docs = new Map<SourceId, Promise<pdfjs.PDFDocumentProxy>>();

function getDoc(source: SourceFile) {
  let p = docs.get(source.id);
  if (!p) { p = pdfjs.getDocument({ data: source.bytes.slice() }).promise; docs.set(source.id, p); }
  return p;
}

export function clearTextCache(sourceId?: string): void {
  for (const k of [...cache.keys()]) if (!sourceId || k.startsWith(`${sourceId}:`)) cache.delete(k);
  if (sourceId) { docs.get(sourceId)?.then((d) => d.loadingTask.destroy()).catch(() => {}); docs.delete(sourceId); }
  else { for (const [, p] of docs) p.then((d) => d.loadingTask.destroy()).catch(() => {}); docs.clear(); }
}

export async function extractPageText(source: SourceFile, pageIndex: number): Promise<PageText> {
  const key = `${source.id}:${pageIndex}`;
  let p = cache.get(key);
  if (!p) {
    p = (async () => {
      const doc = await getDoc(source);
      const page = await doc.getPage(pageIndex + 1);
      const content = await page.getTextContent();
      const raw = content.items.filter((i): i is RawItem & { str: string } => "str" in i) as RawItem[];
      const items: TextItemBox[] = raw.filter((i) => i.str.length > 0).map((i) => ({
        str: i.str, x: i.transform[4], y: i.transform[5], width: i.width, height: i.height,
        fontSize: Math.hypot(i.transform[2], i.transform[3]) || i.height,
      }));
      return { text: linesFromItems(raw), items };
    })();
    cache.set(key, p);
  }
  return p;
}

export async function documentText(scope: "all" | "selected"): Promise<{ page: number; text: string }[]> {
  const { pages, sources, selection } = useDocumentStore.getState();
  const out: { page: number; text: string }[] = [];
  for (let i = 0; i < pages.length; i++) {
    const entry = pages[i];
    if (scope === "selected" && !selection.has(entry.id)) continue;
    const source = sources.get(entry.sourceId)!;
    const { text } = await extractPageText(source, entry.sourcePageIndex);
    out.push({ page: i + 1, text });
  }
  return out;
}
```

```ts
export interface Box { x: number; y: number; width: number; height: number }
export interface PageSelection { pageEntryId: string; text: string; boxes: Box[]; fontSize: number; bold: boolean; serif: boolean }

export function mergeLineRects(rects: DOMRect[]): DOMRect[] {
  const sorted = [...rects].filter((r) => r.width > 0 && r.height > 0).sort((a, b) => a.top - b.top || a.left - b.left);
  const lines: { left: number; top: number; right: number; bottom: number }[] = [];
  for (const r of sorted) {
    const last = lines[lines.length - 1];
    if (last && Math.abs(r.top - last.top) < r.height * 0.5) {
      last.left = Math.min(last.left, r.left); last.right = Math.max(last.right, r.right);
      last.top = Math.min(last.top, r.top); last.bottom = Math.max(last.bottom, r.bottom);
    } else {
      lines.push({ left: r.left, top: r.top, right: r.right, bottom: r.bottom });
    }
  }
  return lines.map((l) => new DOMRect(l.left, l.top, l.right - l.left, l.bottom - l.top));
}

export function rectsToBoxes(rects: DOMRect[], pageRect: DOMRect, scale: number, pageHeightPt: number): Box[] {
  return rects.map((r) => {
    const x = (r.left - pageRect.left) / scale;
    const top = (r.top - pageRect.top) / scale;
    const width = r.width / scale;
    const height = r.height / scale;
    return { x, y: pageHeightPt - top - height, width, height };
  });
}

export function captureSelection(): PageSelection | null {
  const sel = window.getSelection();
  if (!sel || sel.rangeCount === 0 || sel.isCollapsed) return null;
  const range = sel.getRangeAt(0);
  const pageEl = (range.commonAncestorContainer instanceof Element ? range.commonAncestorContainer : range.commonAncestorContainer.parentElement)?.closest<HTMLElement>(".page");
  if (!pageEl) return null;
  const text = sel.toString().replace(/\s+\n/g, "\n").trim();
  if (!text) return null;
  const scale = Number(pageEl.dataset.scale);
  const heightPt = Number(pageEl.dataset.heightPt);
  const rects = mergeLineRects(Array.from(range.getClientRects()));
  if (rects.length === 0) return null;
  const boxes = rectsToBoxes(rects, pageEl.getBoundingClientRect(), scale, heightPt);
  const anchorEl = (sel.anchorNode instanceof Element ? sel.anchorNode : sel.anchorNode?.parentElement) as HTMLElement | null;
  const cs = anchorEl ? getComputedStyle(anchorEl) : null;
  const fontSize = cs ? parseFloat(cs.fontSize) / scale : boxes[0].height * 0.85;
  const family = (cs?.fontFamily ?? "").toLowerCase();
  const bold = cs ? Number(cs.fontWeight) >= 600 || /bold/.test(family) : false;
  const serif = /times|serif|georgia|garamond/.test(family) && !/sans/.test(family);
  return { pageEntryId: pageEl.dataset.pageEntry ?? "", text, boxes, fontSize: Math.round(fontSize * 10) / 10, bold, serif };
}
```

```ts
export interface SseEvent { event: string; data: string }

export function createSseParser(onEvent: (e: SseEvent) => void) {
  let buffer = "";
  const flush = (block: string) => {
    let event = "message";
    const data: string[] = [];
    for (const line of block.split("\n")) {
      if (line.startsWith(":")) continue;
      if (line.startsWith("event:")) event = line.slice(6).trim();
      else if (line.startsWith("data:")) data.push(line.slice(5).trimStart());
    }
    if (data.length) onEvent({ event, data: data.join("\n") });
  };
  return {
    push(chunk: string) {
      buffer += chunk.replace(/\r\n/g, "\n");
      let idx: number;
      while ((idx = buffer.indexOf("\n\n")) !== -1) {
        flush(buffer.slice(0, idx));
        buffer = buffer.slice(idx + 2);
      }
    },
    end() {
      if (buffer.trim()) flush(buffer);
      buffer = "";
    },
  };
}
```

```ts
import { createSseParser } from "./sse";

export interface AiRequest {
  task: "summarize" | "ask" | "rewrite" | "extract";
  document: { page: number; text: string }[];
  question?: string;
  history?: { role: "user" | "assistant"; text: string }[];
  selection?: string;
  mode?: string;
  language?: string;
}
export interface DoneData { usage: { input: number; output: number }; stop: string; remaining: { requests: number; tokens: number }; resetAt: number }
export interface Handlers { onDelta(text: string): void; onDone(d: DoneData): void; onError(code: string, extra?: Record<string, unknown>): void }

export class AiClient {
  private token: string | null = null;
  private baseUrl: string;
  private getTurnstileToken: () => Promise<string>;
  private fetchFn: typeof fetch;

  constructor(opts: { baseUrl: string; getTurnstileToken: () => Promise<string>; fetchFn?: typeof fetch }) {
    this.baseUrl = opts.baseUrl.replace(/\/$/, "");
    this.getTurnstileToken = opts.getTurnstileToken;
    this.fetchFn = opts.fetchFn ?? ((input, init) => fetch(input, init));
  }

  async ensureSession(force = false): Promise<string> {
    if (this.token && !force) return this.token;
    const turnstileToken = await this.getTurnstileToken();
    const res = await this.fetchFn(`${this.baseUrl}/session`, {
      method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify({ turnstileToken }),
    });
    if (!res.ok) throw new Error("verification_failed");
    const body = (await res.json()) as { token: string };
    this.token = body.token;
    return this.token;
  }

  runTask(body: AiRequest, handlers: Handlers): { abort(): void; done: Promise<void> } {
    const controller = new AbortController();
    const done = (async () => {
      let token: string;
      try { token = await this.ensureSession(); } catch { handlers.onError("verification_failed"); return; }
      for (let attempt = 0; attempt < 2; attempt++) {
        let res: Response;
        try {
          res = await this.fetchFn(`${this.baseUrl}/ai`, {
            method: "POST", signal: controller.signal,
            headers: { "content-type": "application/json", authorization: `Bearer ${token}` },
            body: JSON.stringify(body),
          });
        } catch (err) {
          handlers.onError((err as Error).name === "AbortError" ? "interrupted" : "network");
          return;
        }
        if (res.status === 401 && attempt === 0) {
          try { token = await this.ensureSession(true); continue; } catch { handlers.onError("verification_failed"); return; }
        }
        if (!res.ok) {
          const err = (await res.json().catch(() => ({}))) as { error?: string; resetAt?: number; maxChars?: number };
          const extra: Record<string, unknown> = {};
          if (err.resetAt) extra.resetAt = err.resetAt;
          if (err.maxChars) extra.maxChars = err.maxChars;
          handlers.onError(err.error ?? "upstream", Object.keys(extra).length ? extra : undefined);
          return;
        }
        let finished = false;
        const parser = createSseParser((e) => {
          const data = JSON.parse(e.data);
          if (e.event === "delta") handlers.onDelta(data.text);
          else if (e.event === "done") { finished = true; handlers.onDone(data); }
          else if (e.event === "error") { finished = true; handlers.onError(data.error); }
        });
        const reader = res.body!.getReader();
        const decoder = new TextDecoder();
        try {
          for (;;) {
            const { value, done: d } = await reader.read();
            if (d) break;
            parser.push(decoder.decode(value, { stream: true }));
          }
          parser.end();
        } catch (err) {
          if (!finished) handlers.onError((err as Error).name === "AbortError" ? "interrupted" : "network");
          return;
        }
        if (!finished) handlers.onError("interrupted", undefined);
        return;
      }
    })();
    return { abort: () => controller.abort(), done };
  }
}
```

```ts
declare global {
  interface Window { turnstile?: { render(el: string | HTMLElement, opts: Record<string, unknown>): string; remove(id: string): void } }
}

export function getTurnstileToken(siteKey: string): Promise<string> {
  return new Promise((resolve, reject) => {
    const el = document.createElement("div");
    el.style.position = "fixed"; el.style.bottom = "8px"; el.style.right = "8px"; el.style.zIndex = "1000";
    document.body.appendChild(el);
    const cleanup = (id?: string) => { try { if (id) window.turnstile?.remove(id); } catch { /* ignore */ } el.remove(); };
    const start = () => {
      if (!window.turnstile) return reject(new Error("turnstile_unavailable"));
      const id = window.turnstile.render(el, {
        sitekey: siteKey,
        appearance: "interaction-only",
        callback: (token: string) => { cleanup(id); resolve(token); },
        "error-callback": () => { cleanup(id); reject(new Error("turnstile_error")); },
        "timeout-callback": () => { cleanup(id); reject(new Error("turnstile_timeout")); },
      });
    };
    if (window.turnstile) start();
    else {
      const t = setInterval(() => { if (window.turnstile) { clearInterval(t); start(); } }, 100);
      setTimeout(() => { clearInterval(t); if (!window.turnstile) { cleanup(); reject(new Error("turnstile_unavailable")); } }, 10_000);
    }
  });
}
```

```ts
export interface Fact { label: string; value: string; page: number }

export interface AiState {
  client: AiClient | null;
  remaining: { requests: number; tokens: number; resetAt: number } | null;
  limitedUntil: number | null;
  summary: { scope: "all" | "selected"; text: string; status: Status; error: string | null };

});

  client: null,
  noticeDismissed: (() => { try { return localStorage.getItem("ai-notice") === "1"; } catch { return false; } })(),
  ...initial(),

  setClient: (client) => set({ client }),
  setSelection: (selection) => set((s) => ({ rewrite: { ...s.rewrite, selection } })),
  setRewriteMode: (mode) => set((s) => ({ rewrite: { ...s.rewrite, mode } })),
  setLanguage: (language) => set((s) => ({ rewrite: { ...s.rewrite, language } })),
  setSummaryScope: (scope) => set((s) => ({ summary: { ...s.summary, scope } })),
  setDraft: (draft) => set((s) => ({ chat: { ...s.chat, draft } })),
  setRewriteResult: (result) => set((s) => ({ rewrite: { ...s.rewrite, result } })),
  dismissNotice: () => { try { localStorage.setItem("ai-notice", "1"); } catch { /* ignore */ } set({ noticeDismissed: true }); },
  resetForNewDocument: () => set((s) => ({ ...initial(), remaining: s.remaining, limitedUntil: s.limitedUntil })),

  errorMessage(code, extra) {
    switch (code) {
      case "verification_failed": return "Couldn't verify you're human. Try again.";
      case "daily_limit": return `Daily limit reached. Resets at ${fmtTime(Number(extra?.resetAt ?? 0))}.`;
      case "too_fast": return "Slow down a little and try again in a few seconds.";
      case "document_too_large": return "Document is too large to send whole; select pages and try again.";
      case "busy": return "AI is busy, try again in a minute.";
      case "refused": return "Claude declined this request.";
      case "interrupted": return "Response interrupted.";
      case "network": return "Couldn't reach the AI service.";
      case "no_text": return "This PDF has no selectable text. OCR is coming in a later version.";
      default: return "Something went wrong talking to the AI.";
    }
  },

  async run(task) {
    const { client } = get();
    if (!client) return;
    const setTask = (patch: Record<string, unknown>) => set((s) => ({ [task]: { ...(s as unknown as Record<string, object>)[task], ...patch } } as Partial<AiState>));
    const scope = task === "summarize" ? get().summary.scope : "all";
    const document = await documentText(scope);
    if (!hasAnyText(document)) { setTask({ status: "error", error: get().errorMessage("no_text") }); return; }

    const body: AiRequest = { task, document };

      if (!r.selection) return;
      body.selection = r.selection.text; body.mode = r.mode;
      if (r.mode === "translate") body.language = r.language || "English";
      setTask({ result: "", status: "running", error: null });
    } else if (task === "summarize") {
      setTask({ text: "", status: "running", error: null });
    } else {
      setTask({ facts: [], status: "running", error: null });
    }

    let buffer = "";
    await client.runTask(body, {
      onDelta: (t) => {
        buffer += t;
        if (task === "summarize") setTask({ text: buffer });
        else if (task === "rewrite") setTask({ result: buffer });
        else if (task === "ask") set((s) => { const turns = [...s.chat.turns]; turns[turns.length - 1] = { role: "assistant", text: buffer }; return { chat: { ...s.chat, turns } }; });
      },
      onDone: (d) => {
        set({ remaining: { ...d.remaining, resetAt: d.resetAt } });
        if (task === "extract") {
          try { setTask({ facts: (JSON.parse(buffer) as { facts: Fact[] }).facts, status: "done" }); }
          catch { setTask({ status: "error", error: "Couldn't read the extracted facts." }); }

        if (code === "daily_limit") set({ limitedUntil: Number(extra?.resetAt ?? 0) });
        setTask({ status: "error", error: get().errorMessage(code, extra) });
      },
    }).done;
  },
}));
```

```ts
export type Token = { type: "text"; value: string } | { type: "page"; page: number };

export function splitCitations(text: string): Token[] {
  const out: Token[] = [];
  const re = /\(p\.\s*(\d+)(?:\s*[-–]\s*\d+)?\)/g;
  let last = 0; let m: RegExpExecArray | null;
  while ((m = re.exec(text))) {
    if (m.index > last) out.push({ type: "text", value: text.slice(last, m.index) });
    out.push({ type: "page", page: Number(m[1]) });
    last = m.index + m[0].length;
  }
  if (last < text.length) out.push({ type: "text", value: text.slice(last) });
  return out.length ? out : [{ type: "text", value: text }];
}
```

```tsx
  return (
    <div className="md">
      {blocks.map((block, bi) => {
        const lines = block.split("\n");
        if (lines.every((l) => /^\s*[-*]\s+/.test(l))) {
          return <ul key={bi}>{lines.map((l, li) => <li key={li}>{inline(l.replace(/^\s*[-*]\s+/, ""), `${bi}-${li}`)}</li>)}</ul>;
        }
        if (/^#{1,3}\s/.test(lines[0])) return <h4 key={bi}>{inline(lines[0].replace(/^#+\s/, ""), `${bi}`)}</h4>;
```

```ts
import type { Box } from "./types";

export interface Region { x: number; y: number; width: number; height: number }
export interface Line { text: string; x: number; baseline: number }
export type Measure = (text: string, fontSize: number) => number;

export function regionOf(boxes: Box[]): Region {
  const x = Math.min(...boxes.map((b) => b.x));
  const y = Math.min(...boxes.map((b) => b.y));
  const right = Math.max(...boxes.map((b) => b.x + b.width));
  const top = Math.max(...boxes.map((b) => b.y + b.height));
  return { x, y, width: right - x, height: top - y };
}

function wrap(text: string, width: number, size: number, measure: Measure): string[] {
  const lines: string[] = [];
  for (const para of text.split("\n")) {
    let line = "";
    for (const word of para.split(/\s+/).filter(Boolean)) {
      const candidate = line ? `${line} ${word}` : word;
      if (measure(candidate, size) <= width) { line = candidate; continue; }
      if (line) lines.push(line);
      line = "";
      // break long words by character
      let chunk = "";
      for (const ch of word) {
        if (measure(chunk + ch, size) > width && chunk) { lines.push(chunk); chunk = ""; }
        chunk += ch;
      }
      line = chunk;
    }
    lines.push(line);
  }
  return lines;
}

const STEPS = [1, 0.95, 0.9, 0.85, 0.8, 0.75, 0.7];

export function layoutText(text: string, region: Region, fontSize: number, measure: Measure) {
  let chosen = { size: fontSize * 0.7, lines: [] as string[], overflow: true };
  for (const step of STEPS) {
    const size = fontSize * step;
    const lines = wrap(text, region.width, size, measure);
    const fits = lines.length * size * 1.2 <= region.height + size * 0.2;
    if (fits) { chosen = { size, lines, overflow: false }; break; }
    if (step === STEPS[STEPS.length - 1]) chosen = { size, lines, overflow: true };
  }
  const maxLines = Math.max(1, Math.floor((region.height + chosen.size * 0.2) / (chosen.size * 1.2)));
  const visible = chosen.overflow ? chosen.lines.slice(0, maxLines) : chosen.lines;
  const top = region.y + region.height;
  return {
    fontSize: chosen.size,
    overflow: chosen.overflow,
    lines: visible.map((t, i) => ({ text: t, x: region.x, baseline: top - chosen.size - i * chosen.size * 1.2 })),
  };
}
```

```tsx
import { useMemo } from "react";
import type { Edit } from "../pdf/types";
import { layoutText, regionOf } from "../pdf/layout";

const FONT_CSS: Record<Edit["font"], string> = {
  sans: "400 1px Helvetica, Arial, sans-serif",
  "sans-bold": "700 1px Helvetica, Arial, sans-serif",
  serif: "400 1px 'Times New Roman', Times, serif",
};

let ctx: CanvasRenderingContext2D | null = null;
export function measureCss(font: Edit["font"]) {
  return (text: string, size: number) => {
    ctx ??= document.createElement("canvas").getContext("2d");
    if (!ctx) return text.length * size * 0.5;
    ctx.font = FONT_CSS[font].replace("1px", `${size}px`);
    return ctx.measureText(text).width;
  };
}

export default function EditOverlay({ edits, scale, pageHeightPt }: { edits: Edit[]; scale: number; pageHeightPt: number }) {
  const laid = useMemo(() => edits.map((e) => ({ e, ...layoutText(e.text, regionOf(e.boxes), e.fontSize, measureCss(e.font)) })), [edits]);
  return (
    <div className="editOverlay">
      {laid.map(({ e, lines, fontSize }) => (
        <div key={e.id} className="edit" data-edit-id={e.id}>
          {e.boxes.map((b, i) => (
            <div key={i} className="edit-box" style={{ left: b.x * scale, top: (pageHeightPt - b.y - b.height) * scale, width: b.width * scale, height: b.height * scale }} />
          ))}
          {lines.map((l, i) => (
            <div key={i} className="edit-line" style={{ left: l.x * scale, top: (pageHeightPt - l.baseline - fontSize) * scale, font: FONT_CSS[e.font].replace("1px", `${fontSize * scale}px`), color: `rgb(${e.color.map((c) => c * 255).join(",")})` }}>{l.text}</div>
          ))}
        </div>
      ))}
    </div>
  );
}
```

```tsx
import { useMemo } from "react";
import { useAiStore, type RewriteMode } from "../../store/ai";
import { useDocumentStore } from "../../store/document";
import { layoutText, regionOf } from "../../pdf/layout";
import { measureCss } from "../EditOverlay";

const MODES: { value: RewriteMode; label: string }[] = [
  { value: "rewrite", label: "Rewrite" }, { value: "simplify", label: "Simplify" }, { value: "formal", label: "Make formal" },
  { value: "translate", label: "Translate" }, { value: "explain", label: "Explain" },
];

export default function RewriteTab({ disabled }: { disabled: boolean }) {
  const { rewrite, setRewriteMode, setLanguage, setRewriteResult, run, setSelection } = useAiStore();
  const pages = useDocumentStore((s) => s.pages);
  const addEdit = useDocumentStore((s) => s.addEdit);
  const clearSel = useDocumentStore((s) => s.clearSelection);
  const sel = rewrite.selection;
  const entry = sel ? pages.find((p) => p.id === sel.pageEntryId) : undefined;
  const pageEl = sel ? document.querySelector<HTMLElement>(`#page-${sel.pageEntryId}`) : null;
  const effectiveRotation = entry ? ((Number(pageEl?.dataset.pageRotate ?? 0) + entry.rotation) % 360 + 360) % 360 : 0;
  const font = sel ? (sel.serif ? "serif" : sel.bold ? "sans-bold" : "sans") : "sans";
  const fit = useMemo(() => (sel && rewrite.result ? layoutText(rewrite.result, regionOf(sel.boxes), sel.fontSize, measureCss(font)) : null), [sel, rewrite.result, font]);
  const canInsert = !!sel && !!entry && !!fit && !fit.overflow && rewrite.mode !== "explain" && effectiveRotation === 0 && rewrite.status === "done";

  const insert = () => {
    if (!sel || !canInsert) return;
    addEdit({ pageEntryId: sel.pageEntryId, boxes: sel.boxes, text: rewrite.result, fontSize: sel.fontSize, font, color: [0, 0, 0] });
    setSelection(null); setRewriteResult(""); clearSel(); window.getSelection()?.removeAllRanges();
  };

  return (
    <div className="ai-tab">
      {!sel ? <p className="muted">Select text on a page to rewrite it.</p> : (
        <blockquote className="ai-selection">{sel.text.length > 300 ? sel.text.slice(0, 300) + "…" : sel.text}</blockquote>
      )}
      <div className="ai-row">
        <select value={rewrite.mode} onChange={(e) => setRewriteMode(e.target.value as RewriteMode)}>{MODES.map((m) => <option key={m.value} value={m.value}>{m.label}</option>)}</select>
        {rewrite.mode === "translate" && <input placeholder="Language" value={rewrite.language} onChange={(e) => setLanguage(e.target.value)} />}
        <button data-testid="ai-run" className="primary" disabled={disabled || !sel || !entry || rewrite.status === "running" || (rewrite.mode === "translate" && !rewrite.language.trim())} onClick={() => run("rewrite")}>
          {rewrite.status === "running" ? "Working…" : "Run"}
        </button>
      </div>
      {rewrite.error && <div className="ai-error">{rewrite.error}</div>}
      {(rewrite.result || rewrite.status === "running") && (
        <div data-testid="ai-result" className="ai-result">
          <textarea value={rewrite.result} rows={6} onChange={(e) => setRewriteResult(e.target.value)} disabled={rewrite.status === "running"} />
          {fit?.overflow && <div className="ai-error">Too long to fit; shorten the text.</div>}
          {effectiveRotation !== 0 && <div className="ai-error">Rotate the page back to its original orientation to insert text.</div>}
          <div className="ai-row">
            <button onClick={() => navigator.clipboard.writeText(rewrite.result)}>Copy</button>
            <button data-testid="ai-insert" className="primary" disabled={!canInsert} onClick={insert}>Insert into PDF</button>
          </div>
        </div>
      )}
    </div>
  );
}
```
