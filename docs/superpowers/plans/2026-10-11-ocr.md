# OCR for Scanned PDFs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recover text from scanned PDF pages (locally with Tesseract.js, optionally with Claude vision) so Summarize, Ask, Extract, Search, text selection, and the downloaded PDF all work on scans.

**Architecture:** A `src/ocr/` module exposes one `OcrEngine` interface with two implementations (Tesseract.js on the device, Claude through the AI worker). Results live in an IndexedDB store keyed by file SHA-256 and page index. `extractPageText` is the single merge point: when pdf.js finds no text on a page it returns the OCR words instead, so every downstream feature is unchanged. Export writes the words into the PDF as invisible text.

**Tech Stack:** Vite 8, React 19, TypeScript 6, Zustand 5, Vitest 5, pdfjs-dist 6.4, pdf-lib, `idb` 8, Tesseract.js 7.0.0 (Apache-2.0), `@napi-rs/canvas` (dev, fixtures only), Cloudflare Worker with `@anthropic-ai/sdk` and zod.

**Spec:** `docs/superpowers/specs/2026-10-11-ocr-design.md`

## Global Constraints

- Tesseract.js version `7.0.0` exactly (`npm i tesseract.js@7.0.0`). Its worker and core scripts load from Tesseract's jsDelivr defaults; only `langPath` is overridden to `https://cdn.jsdelivr.net/npm/@tesseract.js-data/eng@1.0.0/4.0.0_best_int`. (Ruling: the spec said "bundled by Vite"; production already loads the ONNX runtime from jsDelivr, so the same policy applies and avoids the 25 MiB asset cap. Tesseract.js spawns its own Web Worker, so no custom worker file is needed.)
- Boxes everywhere are PDF user-space points, origin bottom-left, for the unrotated page (same frame as pdf.js `getTextContent`).
- Rasterisation scale = `min(300 / 72, maxEdge / max(widthPt, heightPt))`; `maxEdge` is `2500` for Tesseract, `1568` for Claude.
- Claude JPEG quality `0.85`; re-encode at `1200` then `900` px when over `4_000_000` bytes; fail the page with `"Page image too large"` if still over.
- Deep OCR synthesised layout: margin `36` pt, line height `min(14, (heightPt - 72) / lines.length)`, line width `widthPt - 72`, word confidence `0.9`.
- Tesseract page is `empty` when zero words or page confidence `< 0.3`.
- Per-page timeout `60_000` ms. Worker `ocr` task: 1–20 pages, each base64 image ≤ `5_400_000` chars, `max_tokens` `4000`, effort `"low"`, one Messages call per page.
- localStorage key `pdfstudio.ocr.auto` (absent or `"1"` = on; `"0"` = off). IndexedDB name `pdfstudio-ocr`, store `pages`, key `${hash}:${pageIndex}`.
- Copy, verbatim: badge labels `Recognizing…`, `Text recognized`, `Deep OCR`, `No text found`, `Failed`; pill `Recognizing text {done}/{total}`; AI/Search messages `Recognizing text… try again in a moment.` and `No text could be recognized. Try Deep OCR.`; confirmation `Deep OCR sends images of {N} page(s) to the AI service for transcription. Text stays on this device afterwards.`; toasts `OCR text could not be saved; it will be recognized again next time.` and `Saved without searchable text layer.`
- `npx tsc -b` must pass (root `tsc --noEmit` checks nothing); `npm test`, `npm run worker:test`, `npm run lint` must pass after every task.
- Never commit `.env` or `worker/.dev.vars`.

## Review Focus

1. A scanned page that pdf.js reports with a few junk items (e.g. one whitespace item from a fax header) must still be treated as text-less and OCR'd. Test in Task 5: items whose joined text is whitespace count as no text.
2. Closing a document while its pages are queued must cancel pending jobs and never write results for a source id that no longer exists. Test in Task 7.
3. Re-opening the same scan must not re-run Tesseract (hash hit) and must show "Text recognized" immediately. Test in Task 7.
4. Download of a scan with a rotated page entry must place the invisible text on the unrotated page coordinates (pdf-lib rotates the whole page, text included). Test in Task 9 with a 90° page.
5. Deep OCR on a page that already has Tesseract text must replace it, and the text cache and search index must refresh. Test in Task 7 (cache cleared) and Task 8 (ocrVersion bump re-indexes).

```ts
// src/ocr/layout.ts
import type { TextItemBox } from "../pdf/text";
import type { OcrLine, OcrPage, OcrWord, PageMetaPt } from "./types";

export interface TessBbox { x0: number; y0: number; x1: number; y1: number }
export interface TessWord { text: string; bbox: TessBbox; confidence: number }
export interface TessLine { text: string; bbox: TessBbox; words: TessWord[] }

export const EMPTY_CONFIDENCE = 0.3;
const MARGIN = 36;
const MAX_LINE_HEIGHT = 14;
const CLAUDE_WORD_CONFIDENCE = 0.9;

function toBox(b: TessBbox, scale: number, heightPt: number) {
  return { x: b.x0 / scale, y: heightPt - b.y1 / scale, width: (b.x1 - b.x0) / scale, height: (b.y1 - b.y0) / scale };
}

export function tesseractToOcrPage(lines: TessLine[], pageConfidence: number, scale: number, heightPt: number, at = Date.now()): OcrPage {
  const out: OcrLine[] = [];
  for (const l of lines) {
    const words: OcrWord[] = l.words.filter((w) => w.text.trim().length > 0).map((w) => ({ text: w.text.trim(), box: toBox(w.bbox, scale, heightPt), confidence: w.confidence / 100 }));
    if (words.length === 0) continue;
    out.push({ text: words.map((w) => w.text).join(" "), box: toBox(l.bbox, scale, heightPt), words });
  }
  return { engine: "tesseract", lines: out, confidence: pageConfidence / 100, at };
}

export function linesToOcrPage(rawLines: string[], meta: PageMetaPt, at = Date.now()): OcrPage {
  const texts = rawLines.map((l) => l.trim()).filter((l) => l.length > 0);
  const lineHeight = texts.length === 0 ? MAX_LINE_HEIGHT : Math.min(MAX_LINE_HEIGHT, (meta.heightPt - 2 * MARGIN) / texts.length);
  const width = meta.widthPt - 2 * MARGIN;
  const lines: OcrLine[] = texts.map((text, i) => {
    const y = meta.heightPt - MARGIN - lineHeight * (i + 1);
    const parts = text.split(/\s+/);
    const chars = parts.reduce((n, p) => n + p.length, 0) || 1;
    let x = MARGIN;
    const words: OcrWord[] = parts.map((p) => {
      const w = (width * p.length) / chars;
      const word = { text: p, box: { x, y, width: w, height: lineHeight }, confidence: CLAUDE_WORD_CONFIDENCE };
      x += w;
      return word;
    });
    return { text, box: { x: MARGIN, y, width, height: lineHeight }, words };
  });
  return { engine: "claude", lines, confidence: texts.length ? CLAUDE_WORD_CONFIDENCE : 0, at };
}

export function ocrPageToItems(page: OcrPage): TextItemBox[] {
  return page.lines.flatMap((l) => l.words.map((w) => ({ str: w.text, x: w.box.x, y: w.box.y, width: w.box.width, height: w.box.height, fontSize: l.box.height })));
}

export function ocrPageText(page: OcrPage): string {
  return page.lines.map((l) => l.text).join("\n");
}

export function isEmptyOcr(page: OcrPage): boolean {
  return page.lines.every((l) => l.words.length === 0) || page.confidence < EMPTY_CONFIDENCE;
}
```

```ts
// src/ocr/store.ts
import { openDB, type IDBPDatabase } from "idb";
import type { OcrPage } from "./types";

export interface OcrRecord extends OcrPage { hash: string; pageIndex: number }
const STORE = "pages";
const key = (hash: string, pageIndex: number) => `${hash}:${pageIndex}`;

export function openOcrDb(dbName: string): Promise<IDBPDatabase> {
  return openDB(dbName, 1, { upgrade(d) { if (!d.objectStoreNames.contains(STORE)) d.createObjectStore(STORE); } });
}

type Opener = () => Promise<IDBPDatabase>;

export function createOcrStore(dbName = "pdfstudio-ocr", open?: Opener) {
  const memory = new Map<string, OcrRecord>();
  let db: Promise<IDBPDatabase> | null = null;
  const state = { persistent: true, lastWriteFailed: false };
  const opener: Opener = open ?? (() => openOcrDb(dbName));
  const getDb = async (): Promise<IDBPDatabase | null> => {
    if (!state.persistent) return null;
    try { return await (db ??= Promise.resolve().then(opener)); }
    catch { state.persistent = false; db = null; return null; }
  };
  const strip = (r: OcrRecord): OcrPage => ({ engine: r.engine, lines: r.lines, confidence: r.confidence, at: r.at });
  return {
    get persistent() { return state.persistent; },
    get lastWriteFailed() { return state.lastWriteFailed; },
    async put(hash: string, pageIndex: number, page: OcrPage) {
      const record: OcrRecord = { ...page, hash, pageIndex };
      const d = await getDb();
      if (d) {
        try {
          const tx = d.transaction(STORE, "readwrite");
          await Promise.all([tx.objectStore(STORE).put(record, key(hash, pageIndex)), tx.done]);
          memory.delete(key(hash, pageIndex));
          state.lastWriteFailed = false;
          return;
        } catch { state.lastWriteFailed = true; }
      }
      memory.set(key(hash, pageIndex), record);
    },
    async get(hash: string, pageIndex: number): Promise<OcrPage | undefined> {
      const mem = memory.get(key(hash, pageIndex));
      if (mem) return strip(mem);
      const d = await getDb();
      const r = d ? ((await d.get(STORE, key(hash, pageIndex))) as OcrRecord | undefined) : undefined;
      return r ? strip(r) : undefined;
    },
    async getAll(hash: string): Promise<Map<number, OcrPage>> {
      const out = new Map<number, OcrPage>();
      const d = await getDb();
      if (d) {
        const range = IDBKeyRange.bound(`${hash}:`, `${hash}:￿`);
        for (const r of (await d.getAll(STORE, range)) as OcrRecord[]) out.set(r.pageIndex, strip(r));
      }
      for (const r of memory.values()) if (r.hash === hash) out.set(r.pageIndex, strip(r));
      return new Map([...out.entries()].sort((a, b) => a[0] - b[0]));
    },
    async remove(hash: string) {
      for (const k of [...memory.keys()]) if (k.startsWith(`${hash}:`)) memory.delete(k);
      const d = await getDb();
      if (!d) return;
      try {
        const tx = d.transaction(STORE, "readwrite");
        const range = IDBKeyRange.bound(`${hash}:`, `${hash}:￿`);
        await Promise.all([tx.objectStore(STORE).delete(range), tx.done]);
      } catch { state.lastWriteFailed = true; }
    },
    async clear() {
      memory.clear();
      const d = await getDb();
      if (!d) return;
      try { await d.clear(STORE); state.lastWriteFailed = false; } catch { state.lastWriteFailed = true; }
    },
  };
}

export type OcrStore = ReturnType<typeof createOcrStore>;
export const ocrStore: OcrStore = createOcrStore();
```

```ts
// src/ocr/raster.ts
import type { SourceFile } from "../pdf/types";
import { getPage } from "../pdf/render";
import type { PageMetaPt } from "./types";

export const TESSERACT_MAX_EDGE = 2500;
export const CLAUDE_MAX_EDGE = 1568;

export function rasterScale(meta: PageMetaPt, maxEdge: number): number {
  return Math.min(300 / 72, maxEdge / Math.max(meta.widthPt, meta.heightPt));
}

/** Renders the unrotated page to a canvas (same frame as pdf.js text content). */
export async function rasterizePage(source: SourceFile, pageIndex: number, maxEdge: number): Promise<{ canvas: HTMLCanvasElement; meta: PageMetaPt; scale: number }> {
  const page = await getPage(source, pageIndex);
  const meta = { widthPt: page.view[2] - page.view[0], heightPt: page.view[3] - page.view[1] };
  const scale = rasterScale(meta, maxEdge);
  const viewport = page.getViewport({ scale, rotation: 0 });
  const canvas = document.createElement("canvas");
  canvas.width = Math.ceil(viewport.width); canvas.height = Math.ceil(viewport.height);
  const ctx = canvas.getContext("2d");
  if (!ctx) throw new Error("no 2d context");
  ctx.fillStyle = "white"; ctx.fillRect(0, 0, canvas.width, canvas.height);
  await page.render({ canvas, canvasContext: ctx, viewport }).promise;
  return { canvas, meta, scale };
}

export function canvasToBlob(canvas: HTMLCanvasElement, type: string, quality?: number): Promise<Blob> {
  return new Promise((resolve, reject) => canvas.toBlob((b) => (b ? resolve(b) : reject(new Error("toBlob failed"))), type, quality));
}
```

```ts
// src/ocr/tesseractEngine.ts
import { createWorker } from "tesseract.js";
import { tesseractToOcrPage, type TessLine } from "./layout";
import { canvasToBlob } from "./raster";
import type { OcrEngine, OcrPage, PageMetaPt } from "./types";

export const TESSDATA_URL = "https://cdn.jsdelivr.net/npm/@tesseract.js-data/eng@1.0.0/4.0.0_best_int";

export interface TessRunner { recognize(image: unknown): Promise<{ lines: TessLine[]; confidence: number }>; terminate(): Promise<void> }

async function defaultRunner(): Promise<TessRunner> {
  const worker = await createWorker("eng", 1, { langPath: TESSDATA_URL });
  return {
    async recognize(image) {
      const r = await worker.recognize(image as never, {}, { blocks: true, text: true });
      return { confidence: r.data.confidence, lines: (r.data.blocks ?? []).flatMap((b) => b.paragraphs.flatMap((p) => p.lines)) };
    },
    terminate: () => worker.terminate(),
  };
}

export async function recognizeImage(runner: TessRunner, image: unknown, scale: number, meta: PageMetaPt): Promise<OcrPage> {
  const r = await runner.recognize(image);
  return tesseractToOcrPage(r.lines, r.confidence, scale, meta.heightPt);
}

export function createTesseractEngine(makeRunner: () => Promise<TessRunner> = defaultRunner) {
  let runner: Promise<TessRunner> | null = null;
  let status: "idle" | "loading" | "ready" | "unavailable" = "idle";
  const load = async () => {
    if (!runner) {
      status = "loading";
      runner = makeRunner().then((r) => { status = "ready"; return r; }, (e) => { status = "unavailable"; runner = null; throw e; });
    }
    await runner;
  };
  return {
    get status() { return status; },
    load,
    dispose() { const r = runner; runner = null; status = "idle"; void r?.then((x) => x.terminate()).catch(() => {}); },
    async recognize(canvas: HTMLCanvasElement, meta: PageMetaPt, signal?: AbortSignal): Promise<OcrPage> {
      if (signal?.aborted) throw new Error("cancelled");
      await load();
      if (signal?.aborted) throw new Error("cancelled");
      const r = await runner!;
      const scale = canvas.width / meta.widthPt;
      const blob = await canvasToBlob(canvas, "image/png");
      return recognizeImage(r, blob, scale, meta);
    },
  };
}

let singleton: ReturnType<typeof createTesseractEngine> | null = null;
export function getTesseractEngine() { return (singleton ??= createTesseractEngine()); }
```

Note for the implementer: Tesseract's `ImageLike` type omits `Blob`, but the browser build accepts `Blob`/`File` (documented in its image-format guide), hence the `as never` cast.

```ts
export const OCR_MAX_PAGES = 20;
export const OCR_MAX_IMAGE_CHARS = 5_400_000;
const ocrSchema = z.object({
  task: z.literal("ocr"),
  pages: z.array(z.object({ page: z.number().int().positive(), image: z.string().min(1) })).min(1).max(OCR_MAX_PAGES),
});
export type OcrBody = z.infer<typeof ocrSchema>;
export function validateOcrBody(input: unknown): { ok: true; body: OcrBody } | { ok: false; status: 400 | 413; error: string } {
  const parsed = ocrSchema.safeParse(input);
  if (!parsed.success) return { ok: false, status: 400, error: "invalid_body" };
  if (parsed.data.pages.some((p) => p.image.length > OCR_MAX_IMAGE_CHARS)) return { ok: false, status: 413, error: "image_too_large" };
  return { ok: true, body: parsed.data };
}
```

```ts
// worker/src/handlers/ocr.ts
import type { Env } from "../env";
import { json } from "../cors";
import { verifySession } from "../session";
import { validateOcrBody } from "../validate";
import { checkQuota, recordTokens, DAILY_REQUESTS, DAILY_TOKENS } from "../quota";
import { ocrWithSdk, mapError, type OcrFn } from "../claude";

const TOKENS_PER_PAGE = 1_600; // ~1568px JPEG

export async function ocrHandler(request: Request, env: Env, ctx: ExecutionContext, ocr: OcrFn = ocrWithSdk): Promise<Response> {
  const auth = request.headers.get("authorization") ?? "";
  const token = auth.startsWith("Bearer ") ? auth.slice(7) : "";
  const session = token ? await verifySession(token, env.SESSION_SECRET) : null;
  if (!session) return json({ error: "unauthorized" }, 401, env);
  const declared = Number(request.headers.get("content-length") ?? "0");
  if (declared > 60_000_000) return json({ error: "image_too_large" }, 413, env);
  let raw: unknown;
  try { raw = await request.json(); } catch { return json({ error: "invalid_body" }, 400, env); }
  const v = validateOcrBody(raw);
  if (!v.ok) return json({ error: v.error }, v.status, env);

  const pages = v.body.pages;
  const now = Date.now() / 1000;
  // Each page is one AI request: admit the batch only if every page fits today's quota.
  let quota = await checkQuota(env.QUOTA, session.vid, now, TOKENS_PER_PAGE);
  if (!quota.ok) return json({ error: quota.reason, resetAt: quota.resetAt }, 429, env);
  if (quota.charged.requests + pages.length - 1 > DAILY_REQUESTS) return json({ error: "daily_limit", resetAt: quota.resetAt }, 429, env);
  for (let i = 1; i < pages.length; i++) {
    const q = await checkQuota(env.QUOTA, session.vid, now, TOKENS_PER_PAGE);
    if (!q.ok) return json({ error: q.reason, resetAt: q.resetAt }, 429, env);
    quota = q;
  }

  const out: { page: number; lines: string[] }[] = [];
  const failed: number[] = [];
  let extra = 0;
  for (const p of pages) {
    try {
      const r = await ocr(p.image, env);
      out.push({ page: p.page, lines: r.text.split(/\r?\n/).map((l) => l.trim()).filter((l) => l.length > 0) });
      extra += Math.max(0, r.inputTokens + r.outputTokens - TOKENS_PER_PAGE);
    } catch (err) {
      console.log(JSON.stringify({ task: "ocr", vid: session.vid, page: p.page, status: "error", kind: mapError(err) }));
      failed.push(p.page);
    }
  }
  const state = extra > 0 ? await recordTokens(env.QUOTA, session.vid, quota.day, extra) : quota.charged;
  console.log(JSON.stringify({ task: "ocr", vid: session.vid, pages: pages.length, failed: failed.length }));
  return json({ pages: out, failed, remaining: { requests: Math.max(0, DAILY_REQUESTS - state.requests), tokens: Math.max(0, DAILY_TOKENS - state.tokens) }, resetAt: quota.resetAt }, 200, env);
}
```

```ts
export interface OcrApi { runOcr(pages: { page: number; image: string }[], signal?: AbortSignal): Promise<OcrResponse> }
export const JPEG_QUALITY = 0.85;
export const MAX_JPEG_BYTES = 4_000_000;
const FALLBACK_EDGES = [1200, 900];

export function downscale(c: HTMLCanvasElement, edge: number): HTMLCanvasElement {
  const k = edge / Math.max(c.width, c.height);
  const out = document.createElement("canvas");
  out.width = Math.round(c.width * k); out.height = Math.round(c.height * k);
  out.getContext("2d")!.drawImage(c, 0, 0, out.width, out.height);
  return out;
}

async function toBase64(blob: Blob): Promise<string> {
  const bytes = new Uint8Array(await blob.arrayBuffer());
  let s = "";
  for (let i = 0; i < bytes.length; i += 0x8000) s += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  return btoa(s);
}

export async function encodeJpeg(canvas: HTMLCanvasElement, shrink: (c: HTMLCanvasElement, edge: number) => HTMLCanvasElement = downscale): Promise<string> {
  let current = canvas;
  let blob = await canvasToBlob(current, "image/jpeg", JPEG_QUALITY);
  for (const edge of FALLBACK_EDGES) {
    if (blob.size <= MAX_JPEG_BYTES) break;
    current = shrink(current, edge);
    blob = await canvasToBlob(current, "image/jpeg", JPEG_QUALITY);
  }
  if (blob.size > MAX_JPEG_BYTES) throw new Error("Page image too large");
  return toBase64(blob);
}

export function createClaudeEngine(api: () => OcrApi | null): OcrEngine {
  return {
    async recognize(canvas: HTMLCanvasElement, meta: PageMetaPt, signal?: AbortSignal): Promise<OcrPage> {

      if (!a) throw new Error("not configured");
      const image = await encodeJpeg(canvas);
      if (signal?.aborted) throw new Error("cancelled");
      const r = await a.runOcr([{ page: 1, image }], signal);
      const got = r.pages.find((p) => p.page === 1);
      if (!got) throw new Error("upstream");
      return linesToOcrPage(got.lines, meta);
    },
  };
```

```ts
// src/ocr/queue.ts
import { isEmptyOcr } from "./layout";
import type { OcrEngineName, OcrPage } from "./types";

export type OcrJobState = "queued" | "running" | "done" | "empty" | "failed";
export interface OcrJob { sourceId: string; pageIndex: number; engine: OcrEngineName }
export interface OcrQueueEvents { onState(job: OcrJob, state: OcrJobState, extra?: { page?: OcrPage; error?: string }): void }
export const OCR_TIMEOUT_MS = 60_000;

interface Entry { job: OcrJob; controller: AbortController; running: boolean }
const keyOf = (j: OcrJob) => `${j.sourceId}:${j.pageIndex}:${j.engine}`;

export function createOcrQueue(run: (job: OcrJob, signal: AbortSignal) => Promise<OcrPage>, events: OcrQueueEvents, opts: { timeoutMs?: number; isEmpty?: (p: OcrPage) => boolean } = {}) {
  const timeoutMs = opts.timeoutMs ?? OCR_TIMEOUT_MS;
  const isEmpty = opts.isEmpty ?? isEmptyOcr;
  const lanes = new Map<OcrEngineName, Entry[]>();
  const keys = new Set<string>();

  const pump = (engine: OcrEngineName) => {
    const lane = lanes.get(engine) ?? [];
    const head = lane[0];
    if (!head || head.running) return;
    head.running = true;
    events.onState(head.job, "running");
    const timer = setTimeout(() => head.controller.abort(new Error("timeout")), timeoutMs);
    run(head.job, head.controller.signal).then(
      (page) => { if (!head.controller.signal.aborted) events.onState(head.job, isEmpty(page) ? "empty" : "done", { page }); },
      (err) => {
        const reason = head.controller.signal.reason;
        if (head.controller.signal.aborted && !(reason instanceof Error && reason.message === "timeout")) return; // cancelled: no state
        events.onState(head.job, "failed", { error: reason instanceof Error && reason.message === "timeout" ? "timeout" : err instanceof Error ? err.message : String(err) });
      },
    ).finally(() => {
      clearTimeout(timer);
      const l = lanes.get(engine) ?? [];
      if (l[0] === head) l.shift();
      keys.delete(keyOf(head.job));
      pump(engine);
    });
  };

  return {
    enqueue(job: OcrJob) {
      const k = keyOf(job);
      if (keys.has(k)) return;
      keys.add(k);
      const lane = lanes.get(job.engine) ?? [];
      lanes.set(job.engine, lane);
      lane.push({ job, controller: new AbortController(), running: false });
      events.onState(job, "queued");
      queueMicrotask(() => pump(job.engine));
    },
    cancelSource(sourceId: string) {
      for (const [engine, lane] of lanes) {
        for (const e of [...lane]) {
          if (e.job.sourceId !== sourceId) continue;
          if (e.running) e.controller.abort(new Error("cancelled"));
          else { lane.splice(lane.indexOf(e), 1); keys.delete(keyOf(e.job)); }
        }
        pump(engine);
      }
    },
    cancelAll() { for (const lane of lanes.values()) for (const e of [...lane]) this.cancelSource(e.job.sourceId); },
    get pending() { let n = 0; for (const lane of lanes.values()) n += lane.length; return n; },
  };
}
```

```ts
import { useDocumentStore } from "./document";
import { useAiStore } from "./ai";
import type { SourceFile, SourceId } from "../pdf/types";
import { extractPageText, invalidatePageText } from "../pdf/text";
import { createOcrQueue, type OcrJob, type OcrJobState } from "../ocr/queue";

export const AUTO_KEY = "pdfstudio.ocr.auto";
export const pageKey = (sourceId: string, pageIndex: number) => `${sourceId}:${pageIndex}`;
export type OcrPageState = { state: OcrJobState; engine?: OcrEngineName; error?: string };

export interface OcrDeps {
  rasterize: typeof rasterizePage;
  tesseract: () => OcrEngine & { load(): Promise<void>; status: string };
  claude: () => OcrEngine;
  store: OcrStore;

const deps: OcrDeps = {
  rasterize: rasterizePage,
  tesseract: getTesseractEngine,
  claude: () => createClaudeEngine(() => useAiStore.getState().client),
  store: defaultOcrStore,
  // "Has native text": OCR-backed text does not count, so cached scans still get a badge and can be Deep OCR'd.
  hasText: async (source, page) => { const t = await extractPageText(source, page); return !t.ocr && t.text.trim().length > 0; },

export function configureOcrDeps(partial: Partial<OcrDeps>): void { Object.assign(deps, partial); }

export interface OcrState {
  enabled: boolean;
  engineStatus: "idle" | "loading" | "ready" | "unavailable";
  engineError: string | null;
  pages: Record<string, OcrPageState>;
  deepOcrAcknowledged: boolean;

const readEnabled = () => { try { return localStorage.getItem(AUTO_KEY) !== "0"; } catch { return true; } };
const scanned = new Set<string>(); // pageKeys known to have no pdf.js text
const errorCopy = (code: string): string => {
  const m = useAiStore.getState().errorMessage(code);
  return code === "Page image too large" ? code : m;
};

const queue = createOcrQueue(async (job, signal) => {
  const source = useDocumentStore.getState().sources.get(job.sourceId);
  if (!source) throw new Error("cancelled");
  const engine = job.engine === "tesseract" ? deps.tesseract() : deps.claude();
  const { canvas, meta } = await deps.rasterize(source, job.pageIndex, job.engine === "tesseract" ? TESSERACT_MAX_EDGE : CLAUDE_MAX_EDGE);
  if (signal.aborted) throw new Error("cancelled");
  return engine.recognize(canvas, meta, signal);
}, {
  onState(job, state, extra) {
    const { setState, getState } = useOcrStore;
    const k = pageKey(job.sourceId, job.pageIndex);
    const source = useDocumentStore.getState().sources.get(job.sourceId);
    if (!source) return;
    if (state === "done" && extra?.page) {
      void (async () => {
        if (source.hash) {
          await deps.store.put(source.hash, job.pageIndex, extra.page!);
          if (deps.store.lastWriteFailed && !getState().lastWriteFailed) setState({ lastWriteFailed: true, toast: "OCR text could not be saved; it will be recognized again next time." });
        }
        invalidatePageText(job.sourceId, job.pageIndex);
        setState((s) => ({ pages: { ...s.pages, [k]: { state: "done", engine: job.engine } } }));
      })();
      return;
    }
    if (state === "failed" && job.engine === "claude") {
      // Keep the Tesseract text if any; report the reason once.
      const prev = getState().pages[k];
      setState((s) => ({ toast: errorCopy(extra?.error ?? "upstream"), pages: { ...s.pages, [k]: prev?.state === "done" ? prev : { state: "failed", engine: "claude", error: extra?.error } } }));
      return;
    }
    if (state === "failed" && extra?.error && /cdn|load|worker|wasm|fetch/i.test(extra.error) && deps.tesseract().status === "unavailable") {
      setState({ engineStatus: "unavailable", engineError: extra.error });
    }
    setState((s) => ({ pages: { ...s.pages, [k]: { state, engine: job.engine, ...(extra?.error ? { error: extra.error } : {}) } } }));
  },
});

async function enqueueTesseract(sourceId: string, pageIndex: number) {
  useOcrStore.setState({ engineStatus: deps.tesseract().status === "unavailable" ? "unavailable" : "loading" });
  try { await deps.tesseract().load(); useOcrStore.setState({ engineStatus: "ready", engineError: null }); }
  catch (err) {
    const message = err instanceof Error ? err.message : String(err);
    // Mark the page failed so retryEngine() can find and re-queue it once the engine loads.
    useOcrStore.setState((s) => ({ engineStatus: "unavailable", engineError: message, pages: { ...s.pages, [pageKey(sourceId, pageIndex)]: { state: "failed", engine: "tesseract", error: message } } }));
    return;
  }
  queue.enqueue({ sourceId, pageIndex, engine: "tesseract" });
}

export const useOcrStore = create<OcrState>((set, get) => ({
  enabled: readEnabled(),
  engineStatus: "idle", engineError: null, pages: {}, deepOcrAcknowledged: false, lastWriteFailed: false, toast: null,

  setEnabled(on) { try { localStorage.setItem(AUTO_KEY, on ? "1" : "0"); } catch { /* ignore */ } set({ enabled: on }); },
  acknowledgeDeepOcr() { set({ deepOcrAcknowledged: true }); },
  clearToast() { set({ toast: null }); },

  async scanSource(sourceId) {
    const source = useDocumentStore.getState().sources.get(sourceId);
    if (!source) return;
    for (let p = 0; p < source.pageCount; p++) {
      if (await deps.hasText(source, p)) continue;
      const k = pageKey(sourceId, p);
      scanned.add(k);
      if (!useDocumentStore.getState().sources.has(sourceId)) return;
      const cached = source.hash ? await deps.store.get(source.hash, p) : undefined;
      if (cached) { invalidatePageText(sourceId, p); set((s) => ({ pages: { ...s.pages, [k]: { state: "done", engine: cached.engine } } })); continue; }
      if (!get().enabled) continue;
      await enqueueTesseract(sourceId, p);
    }
  },
  retryPage(sourceId, pageIndex) { void enqueueTesseract(sourceId, pageIndex); },
  async retryEngine() {
    set({ engineStatus: "idle", engineError: null });
    const { sources } = useDocumentStore.getState();
    for (const [id] of sources) {
      for (const [k, st] of Object.entries(get().pages)) {
        if (!k.startsWith(`${id}:`) || st.state !== "failed" || st.engine !== "tesseract") continue;
        await enqueueTesseract(id, Number(k.slice(id.length + 1)));
        if (get().engineStatus === "unavailable") return;
      }
    }
  },
  async deepOcr(target) {
    const doc = useDocumentStore.getState();
    const ids = target === "all-scanned" ? get().scannedPageEntries() : target;
    for (const id of ids) {
      const entry = doc.pages.find((p) => p.id === id);
      if (!entry) continue;
      const k = pageKey(entry.sourceId, entry.sourcePageIndex);
      if (target !== "all-scanned" && !scanned.has(k)) continue; // pages with real text are never sent
      queue.enqueue({ sourceId: entry.sourceId, pageIndex: entry.sourcePageIndex, engine: "claude" });
    }
  },
  cancelAll() { queue.cancelAll(); },
  async clearAll() { queue.cancelAll(); scanned.clear(); await deps.store.clear(); set({ pages: {}, toast: null, lastWriteFailed: false }); },

  scannedPageEntries() {
    const doc = useDocumentStore.getState();
    return doc.pages.filter((p) => scanned.has(pageKey(p.sourceId, p.sourcePageIndex))).map((p) => p.id);
  },
  progress() {
    const doc = useDocumentStore.getState();
    let total = 0, done = 0;
    for (const [k, st] of Object.entries(get().pages)) {
      const sid = k.slice(0, k.lastIndexOf(":"));
      if (!doc.sources.has(sid) || st.engine !== "tesseract") continue;
      if (st.state === "queued" || st.state === "running") total++;
      else { total++; done++; }
    }
    return total > done ? { done, total } : null;
  },
  textStatus() {
    const doc = useDocumentStore.getState();
    let any = false, pending = false, ok = false;
    for (const p of doc.pages) {
      const st = get().pages[pageKey(p.sourceId, p.sourcePageIndex)];
      if (!st) continue;
      any = true;
      if (st.state === "queued" || st.state === "running") pending = true;
      if (st.state === "done") ok = true;
    }
    if (pending) return "recognizing";
    return any && !ok ? "none" : "ok";
  },
}));

useDocumentStore.subscribe((s, prev) => {

  }

});
```

```ts
// src/ocr/textLayer.ts
import { PDFFont, PDFPage, beginText, endText, setFontAndSize, setTextMatrix, setTextRenderingMode, showText, TextRenderingMode, pushGraphicsState, popGraphicsState } from "pdf-lib";
import { toWinAnsi } from "../pdf/winansi";
import type { OcrPage } from "./types";

const ASCENT = 0.8; // baseline sits this far below the box top, as a fraction of box height

/** Draws every OCR word as invisible text (render mode 3) so other readers can search and select it. */
export function addInvisibleText(page: PDFPage, font: PDFFont, ocr: OcrPage, cropOrigin: { x: number; y: number }): void {
  const fontKey = page.node.newFontDictionary(font.name, font.ref);
  const ops = [pushGraphicsState(), beginText(), setTextRenderingMode(TextRenderingMode.Invisible)];
  for (const line of ocr.lines) {
    for (const w of line.words) {
      const text = toWinAnsi(w.text).replace(/[^\x20-\xFF]/g, "?");
      if (!text.trim()) continue;
      const size = Math.max(1, w.box.height * 0.9);
      const natural = font.widthOfTextAtSize(text, size) || 1;
      const sx = w.box.width / natural;           // squeeze or stretch so the word spans its box
      const x = w.box.x + cropOrigin.x;
      const y = w.box.y + cropOrigin.y + w.box.height * (1 - ASCENT);
      ops.push(setFontAndSize(fontKey, size), setTextMatrix(sx, 0, 0, 1, x, y), showText(font.encodeText(text)));
    }
  }
  ops.push(endText(), popGraphicsState());
  page.pushOperators(...ops);
}
```

```ts
import { test, expect } from "@playwright/test";
import { readFileSync } from "node:fs";
import { join } from "node:path";

test.skip(!process.env.E2E_OCR, "set E2E_OCR=1 to run the OCR tests (downloads Tesseract from jsDelivr)");

const scan = () => ({ name: "scan.pdf", mimeType: "application/pdf", buffer: readFileSync(join(process.cwd(), "src/test/fixtures/scan.pdf")) });

test("recognizes a scanned page, makes it selectable, and summarizes it", async ({ page }) => {
  test.setTimeout(180_000);
  await page.route("**/session", (r) => r.fulfill({ json: { token: "t", expiresAt: 9999999999 } }));
  await page.route("**/ai", (r) => r.fulfill({ headers: { "content-type": "text/event-stream" }, body: 'event: delta\ndata: {"text":"Summary of the scan."}\n\nevent: done\ndata: {"usage":{"input":1,"output":1},"stop":"end_turn","remaining":{"requests":19,"tokens":1},"resetAt":0}\n\n' }));
  await page.goto("/");
  await page.setInputFiles('input[type="file"]', scan());
  await expect(page.getByTestId("ocr-badge").first()).toHaveText("Text recognized", { timeout: 120_000 });
  await expect(page.locator(".page .textLayer span").first()).toBeVisible();
  await expect(page.locator(".page .textLayer")).toContainText(/hypertension/i);
  await page.getByTestId("ai-tab-summarize").click();
  await page.getByRole("button", { name: /Summarize/ }).click();
  await expect(page.getByText("Summary of the scan.")).toBeVisible({ timeout: 30_000 });
});

test("Deep OCR against a mocked worker replaces the page text", async ({ page }) => {
  test.setTimeout(180_000);
  await page.route("**/session", (r) => r.fulfill({ json: { token: "t", expiresAt: 9999999999 } }));
  await page.route("**/ocr", (r) => r.fulfill({ json: { pages: [{ page: 1, lines: ["Handwritten order: hold warfarin"] }], failed: [], remaining: { requests: 18, tokens: 1 }, resetAt: 0 } }));
  await page.goto("/");
  await page.setInputFiles('input[type="file"]', scan());
  await expect(page.getByTestId("ocr-badge").first()).toHaveText("Text recognized", { timeout: 120_000 });
  page.once("dialog", (d) => d.accept());
  await page.getByTestId("deep-ocr").locator("summary").click();
  await page.getByRole("button", { name: "This page" }).click();
  await expect(page.getByTestId("ocr-badge").first()).toHaveText("Deep OCR", { timeout: 30_000 });
  await expect(page.locator(".page .textLayer")).toContainText("warfarin");
});

test("downloaded PDF contains the recognized words", async ({ page }) => {
  test.setTimeout(180_000);
  await page.goto("/");
  await page.setInputFiles('input[type="file"]', scan());
  await expect(page.getByTestId("ocr-badge").first()).toHaveText("Text recognized", { timeout: 120_000 });
  const [download] = await Promise.all([page.waitForEvent("download"), page.getByTestId("download").click()]);
  const bytes = readFileSync(await download.path() as string);
  const { getDocument } = await import("pdfjs-dist/legacy/build/pdf.mjs");
  const pdf = await getDocument({ data: new Uint8Array(bytes) }).promise;
  const text = (await (await pdf.getPage(1)).getTextContent()).items.map((i) => ("str" in i ? i.str : "")).join(" ");
  expect(text).toMatch(/hypertension/i);
});
```
